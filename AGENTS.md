# AGENTS.md

Guide for coding agents working on GameTimeTracker (Tauri 2 + React + TypeScript, Windows only).

## Layout

```
src/                     React frontend
  App.tsx                routes (/, /games, /sessions, /stats, /settings)
  bindings.ts            GENERATED by tauri-specta; never edit by hand
  components/ui/         shadcn components (generated; avoid hand edits)
  components/            app shell and shared components
  hooks/                 TanStack Query hooks wrapping commands
  pages/                 one file per route
src-tauri/src/
  lib.rs                 builder, plugins, tray, window events, specta builder
  commands/mod.rs        Tauri commands (the only IPC entry points)
  error.rs               AppError (serialised to the frontend as a string)
  state.rs               AppState (db Mutex, paths), LogGuard
  core/db/               open(), migrations.rs (append-only, tracked by user_version)
  core/tracker|idle|importers|limits|export/   domain logic; no Tauri types
src-tauri/tests/         Rust tests (bindings export, db)
```

Commands and the specta builder live in `lib.rs` (`specta_builder()`). Events, when added, are registered on the same builder.

## Adding a command

1. Write `#[tauri::command] #[specta::specta] pub fn ...` in `src-tauri/src/commands/`. Argument and return types derive `specta::Type`; errors use `AppResult`.
2. Add it to `collect_commands![...]` in `specta_builder()` in `lib.rs`.
3. Run `cargo test --manifest-path src-tauri/Cargo.toml` (or start the app in debug) to regenerate `src/bindings.ts`, and commit it.
4. Add a hook in `src/hooks/` using `commands.<name>()` with TanStack Query.

Schema changes: append a new migration in `core/db/migrations.rs`; never edit a released one. Timestamps are UTC unix seconds.

## Verify before finishing

```
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml
npm run lint
npm test -- --run
npm run build
```

## Rules

- Use npm (not pnpm/yarn).
- Tracking runs in a Rust background task, never in the webview.
- **Process safety: never kill a process you did not start.** No `Stop-Process` by name, no `taskkill /IM`, no `pkill`. Stop only a process by the exact PID you captured, and prefer commands that exit on their own. Do not run `npm run tauri dev` unless a task needs it.
